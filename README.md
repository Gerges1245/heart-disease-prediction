# ❤️ Heart Disease Prediction

A machine learning project that predicts heart disease risk using clinical data — with full EDA, feature selection, preprocessing, and model comparison.

## 📖 About

Using the **Heart 2020 Cleaned Dataset**, this project walks through a complete ML pipeline: exploratory analysis, preprocessing, feature selection, model training, and evaluation.

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** pandas, numpy, scikit-learn, seaborn, matplotlib, XGBoost
- **EDA:** ydata-profiling (auto HTML report)
- **Environment:** Jupyter Notebook

## ✨ Features

- 📊 **Full EDA** — distributions, correlations, class balance analysis
- 🔧 **Preprocessing** — encoding, scaling, handling imbalanced data
- 🎯 **Feature Selection** — statistical methods to select best predictors
- 🤖 **Multiple Models** — Logistic Regression, Random Forest, XGBoost, etc.
- 📈 **Evaluation** — accuracy, precision, recall, F1, ROC-AUC
- 📋 **Auto HTML Report** — full profiling report generated with ydata-profiling

## 📁 Files

| File | Description |
|------|-------------|
| `heart_disease_prediction.ipynb` | Full ML pipeline notebook |
| `EDA_Report.html` | Auto-generated profiling report |

## 🚀 Getting Started

```bash
pip install -r requirements.txt
jupyter notebook heart_disease_prediction.ipynb
```
